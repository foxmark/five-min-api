# New API Resource Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a complete new API resource to the Symfony/API Platform app — from a written spec to passing integration tests.

**Architecture:** API DTO (`FooResource`) ↔ `FooMapper` ↔ `Foo` entity, served by the existing `GenericDtoProvider` / `GenericDtoProcessor`. Doctrine events fire via `NotifiableInsertInterface` / `NotifiableUpdatedInterface` and are logged by `FooEventSubscriber`. Tests use `ApiPlatform\Symfony\Bundle\Test\ApiTestCase` against a real test database.

**Tech Stack:** Symfony 7.4, API Platform 4.x, Doctrine ORM, PHPUnit 11, Docker (`docker compose exec php`)

> **Template note:** `Foo` / `foo` / `foos` are placeholders. Replace every occurrence with the actual entity name (PascalCase / camelCase / plural lowercase) once the spec is written in Task 1.
